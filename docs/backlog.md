# Список задач

Временный список до переноса в GitHub Issues (`rustemnasyrov/solidbrew-plm`). Перенесённые задачи отмечаются номером.

## 1. Esc закрывает окна без предупреждения и прерывает операции
В окне «Постановка на учёт» во время чтения ссылок Esc сразу закрыл окно, чтение прервалось. Причина: у кнопок «Закрыть»/«Отмена» стоит `IsCancel="True"` — так в окнах постановки, сдачи, переименования, открытия, выгрузки, стартовом, администрирования, настроек.

Нужно: если идёт операция или в окне есть несохранённые решения (отметки, выбранные варианты ссылок, комментарий), Esc и крестик спрашивают «Прервать … и закрыть окно?». Отказ — работа продолжается; согласие — корректная отмена (временные копии удалены, на сервере ничего не опубликовано). Без операции и решений — закрывается сразу. Тесты ViewModel на каждое окно.

## 2. Постановка на учёт: групповые отметки и понятные категории
В отчёте «Найдены за пределами папок» (и «Совпали только по имени») каждую ссылку приходится отмечать отдельно, нет «Выбрать все».

Нужно:
- у каждой категории — «Отметить все» / «Снять все» и счётчик «отмечено N из M»;
- под заголовком категории — одна строка, что это значит и что будет при отметке (например: «Файл найден по сохранённому пути, но вне выбранных папок. Отметьте — он будет поставлен на учёт вместе с изделием; не отмечайте — ссылка останется отсутствующей»);
- группировка по папке источника (часто все такие файлы лежат в одной папке — библиотека, Toolbox, другой проект) с отметкой всей папки сразу;
- кнопка «Добавить эту папку в папки поиска» — перечитать отчёт с ней.

## 3. Постановка на учёт: ссылки на уже учтённые документы и библиотеку
Файлы «за пределами папок» часто — стандартные и покупные изделия, библиотека, Toolbox, детали другого изделия, которые уже стоят на учёте или должны лежать в «Библиотеке» (ТЗ, раздел 8). Сейчас постановка может только скопировать их в проект изделия как новые документы.

Нужно:
- при постановке сопоставлять ссылку с уже учтёнными документами (по хешу содержимого, затем по пути/имени с подтверждением) и ссылаться на их опубликованную версию, а не создавать дубликат;
- для файлов из папок, помеченных администратором как библиотечные (настройка сервера: список путей), — предлагать поставить их в проект «Библиотека» (только администратор) или сослаться на уже учтённые;
- файлы на другом диске (в пилоте 10 ссылок на `Z:\`) — не ломать общий корень относительных путей: такие документы получают путь относительно своей папки и кладутся в подпапку источника.
