# Границы первого пилота

Первая карточка: **АИРТ.467124.016 — Имитатор центрального пульта**, сборочная единица для тренировочного контура. Вышестоящую карточку тренажёра и вхождение в неё заведём по фактическому обозначению и верхней спецификации, когда они будут доступны.

Первичные файлы — одноимённые SLDASM и SLDDRW. На исходной сетевой папке работаем только на чтение. В первичной описи 11 SLDASM, 29 SLDDRW, 117 SLDPRT и 20 других файлов. Опись не доказывает ни замкнутость ссылок CAD, ни комплектность КД. Отдельного файла спецификации по первичной описи не обнаружено; таблица в чертеже не проверена.

## Результат проверки переданной папки

API SOLIDWORKS (`26.1.0`) вернул 129 записей ссылок для сборки и 130 для чертежа. В обоих случаях нет двух деталей: **АИРТ.466938.021 — Пульт вычислитель ПВ-2** и **АИРТ.466938.023 — Пульт управления радиостанции Прима-ДМВ**. По сохранённым путям на этом компьютере файлов также нет. Совпадение остальных ссылок по имени — только кандидат на восстановление, не проверка открытия. Полный отчёт: `artifacts/solidworks-references.json`.

Подготовлен `artifacts/pilot-source.zip`: 177 файлов из переданной папки, 72 253 709 байт. Это исходный снимок для загрузки, не релиз.

## Что разделяем

- Карточка изделия: обозначение, наименование, вид.
- КД и файлы: чертёж, модель, проект ECAD и производственные представления — разные вещи.
- Снимок CAD: неизменяемый набор файлов с исходными относительными путями, хешами и отчётом о ссылках.
- Состав по ЕСКД: отдельно проверяемые позиции, количества, разделы и единицы. Не выводим автоматически из имени CAD-файла или перечня ссылок.
- Выпуск: отдельно утверждённый набор точных версий КД и состава. Импорт непроверенной папки не является выпуском.

## Приёмка

1. Прочитать ссылки головной сборки и чертежа, отдельно отметить отсутствующие и сохранённые вне исходной папки ссылки.
2. Принять пакет как рабочий снимок. Распаковать его в новый каталог, сохраняя имена файлов, и проверить открытие в SOLIDWORKS без доступа к исходным папкам и без ранее открытых одноимённых документов. Проверить реальные пути загруженных файлов.
3. Сохранить второй рабочий снимок и доказать, что первый скачивается с прежними байтами.
4. Реальный выпуск проверять только после сверки спецификации и комплекта КД с ответственным инженером. KiCad, надстройка SOLIDWORKS и работа нескольких инженеров проверяются отдельными сценариями.
